# RYU LLC

Software development studio based in Tokyo, Japan. We build and operate production
systems end to end — mobile and web applications, backend services, and the AWS
infrastructure they run on.

### What we work on

- **Cloud & DevOps** — AWS (ECS/Fargate, Lambda, RDS, ElastiCache, ALB, Route 53,
  CloudFront, VPC, IAM, SSM), Terraform, Ansible, Docker, Kubernetes,
  GitHub Actions, CloudWatch
- **Backend** — Go, Java / Spring Boot, Node.js, Python, PostgreSQL, MySQL, Redis, Kafka
- **Mobile & Frontend** — Flutter, Swift, Kotlin, Next.js, TypeScript
- **Blockchain** — Ethereum node operations, wallet and key isolation

### Open source

| Project | What it is |
|---|---|
| **[market-monitor](https://github.com/ryuclub/market-monitor)** | Crypto market dashboard — Binance real-time candlesticks, technical indicators, signal scoring, backtesting. Pure frontend, zero dependencies. |
| **[video-studio](https://github.com/ryuclub/video-studio)** | Article-to-video pipeline across four content lines. Every frame is drawn in code as SVG — no stock footage compositing. |
| **[telegram-bot](https://github.com/ryuclub/telegram-bot)** | Telegram group moderation — emoji-based join verification and Claude-powered spam classification. |
